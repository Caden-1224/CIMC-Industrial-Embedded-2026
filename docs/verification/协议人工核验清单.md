## 解析器人工用例

- [ ] 小写十六进制输入可以被接受，或在解析前被明确规范化为大写。
- [ ] ASCII-Hex 帧前后的空白字符由 RS485 服务层剥离，不进入协议解析。
- [ ] 非十六进制字符会在 CRC 校验前被拒绝。
- [ ] ASCII-Hex 字符数为奇数时会被拒绝。
- [ ] 短于协议最小固定长度的帧会被拒绝。
- [ ] 帧头错误会被拒绝。
- [ ] 帧尾错误会被拒绝。
- [ ] payload 长度与长度字段不一致时会被拒绝。
- [ ] CRC 不匹配时会被拒绝。
- [ ] 协议版本不是 `0x02` 时会被拒绝。
